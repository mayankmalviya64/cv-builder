# CV Builder

Build a one-page A4 CV where **every bullet fills exactly one line, to the brim**.

**Live:** https://mayankmalviya64.github.io/cv-builder/

## What it does

- **Live brim meter on every bullet, benchmarked against Skynet** (the CV portal IIM Mumbai uses). Each bullet is measured in EB Garamond 9.75pt against the real width of its column on a Skynet PDF:
  | Section style | Line capacity |
  |---|---|
  | Experience / Projects (category column) | 452.125pt |
  | POR / Awards (category + year column) | 421.5pt |

  A bullet scores as **at the brim** when it fills 98–100% of its line. Underfilled bullets show how many px or characters to add. Bullets that spill onto a 2nd line show how much to trim and flag orphan words.
- **One-click micro-tweaks**, e.g. "and" → "&" or "Cr" → "Crore", each showing the fill % it would give.
- **Live A4 preview** in the institute CV layout, with colour highlights. Click a bullet in the preview to jump to it in the editor.
- **Page-fit check:** warns, and draws a red line, when content runs past one A4 page.
- **Download PDF** through the browser's print dialog ("Save as PDF").
- **Autosave** in your browser, plus **Export/Import** as a `.json` file.

## Writing tips inside the editor

- Wrap words in `**double stars**` to make them **bold**, or select the words and press **Ctrl/⌘+B**.
- A bold space is wider than a normal one (2.31pt vs 1.95pt). If Skynet bolds the space after a word (that happens when the selection you bolded included it), write it inside the stars, `**CRM **personalization`, so the meter counts it the same way.
- **Enter** adds a new bullet below. **Backspace** in an empty bullet deletes it.

## How the measuring works

Skynet builds the PDF with iText, which measures a line by simply adding up each character's width from the font file. It uses no kerning and no ligatures. `js/metrics.js` holds those same widths, copied from EB Garamond by `tools/build_metrics.py`. `js/measure.js` adds them up and wraps words the same greedy way. Checked against real Skynet CVs, the meter matches Skynet's line widths to ±0.05pt. Line capacities come from the widest lines Skynet kept on one line and the narrowest it wrapped.

Two Skynet quirks are copied:
- **₹**: Skynet's EB Garamond has no rupee sign, so Skynet draws it in DejaVu Sans, which is wider (6.2pt instead of 4.6pt). The meter and the preview both use the wider width.
- **No kerning or ligatures**: the preview turns them off too, so on-screen widths equal the meter's widths.

The preview (`css/cv.css`) copies Skynet's page geometry: 550pt boxes, column widths, row heights, grey shades, the ■ marker and font sizes. Printing it lands within about 1pt of a Skynet PDF.

## Project layout

```
index.html        page shell
css/app.css       builder interface
css/cv.css        the A4 CV page + print rules
js/metrics.js     EB Garamond character widths (generated by tools/build_metrics.py)
js/measure.js     brim engine (font loading, measuring, grading, tweaks)
js/sample.js      starting CV data + blank templates
js/preview.js     CV data → HTML
js/store.js       autosave, import/export, path helpers
js/editor.js      the form on the left
js/app.js         wires everything together
fonts/            EB Garamond (full font, OFL licence), the same file metrics.js is built from
tools/            build_metrics.py, regenerates js/metrics.js
```

No build step: open `index.html` through any static server (e.g. `python3 -m http.server`).
